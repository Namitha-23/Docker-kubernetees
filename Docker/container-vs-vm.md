# Container vs Virtual Machine

## Virtual Machine
A Virtual Machine includes:
- Application
- Libraries
- Guest OS

Each VM has its own operating system.

## Container
A Container includes:
- Application
- Libraries

Containers share the host operating system kernel.

## Key Difference
Containers are lightweight and start faster than Virtual Machines.

## Real-World Example
In AKS, applications run inside containers, allowing multiple applications to efficiently share the same node.
